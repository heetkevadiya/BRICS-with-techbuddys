# BRICS-frontend — Citizen, Analyst & Policymaker interfaces

Frontend for the multilingual AI Digital Public Good built for **Build with AI: Code for Communities (2nd edition)**, Track 01 — AI for Digital Public Infrastructure & Governance.

## Stack
React 19 · Vite · Tailwind CSS v4 · React Router · Recharts · Google Maps Platform · Firebase Auth

## Run locally
```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:5173 — /api is proxied to the backend on :8000
```

Backend lives in [BRICS-backend](https://github.com/heetkevadiya/BRICS-backend).
